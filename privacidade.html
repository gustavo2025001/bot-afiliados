Política de Privacidade

O Bot Afiliados / Afiliados Premium usa dados fornecidos pelo usuário e dados necessários às integrações autorizadas para oferecer recursos de conta, automação e publicação.

Dados tratados

Podem incluir dados de cadastro, identificadores de conta e informações/tokens necessários às integrações que o próprio usuário autorizar.

Finalidade

Os dados são usados para autenticar o usuário, manter sua conta, conectar serviços autorizados e executar as funcionalidades solicitadas no Bot Afiliados.

Compartilhamento e segurança

Não usamos os dados para finalidades incompatíveis com o serviço. Integrações com terceiros também estão sujeitas às políticas das respectivas plataformas. Adotamos medidas técnicas para limitar o acesso aos dados necessários ao funcionamento do serviço.

Exclusão

Para solicitar exclusão, consulte as instruções de exclusão de dados.
